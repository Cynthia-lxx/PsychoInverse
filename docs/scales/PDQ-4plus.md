## 2. 作答格式

```js
const PDQ_FMT = makeLikert(2, ['否', '是']);   // 级别 0=否, 1=是
const PDQ_FMTS = Array(107).fill('likert');    // 若用中文版
```

- 各条目答「是」记 1 分，「否」记 0 分；**各分量表得分 = 所属条目之和**。
- **无反向题**。
- ⚠️ 有资料提到个别条目为「括号外/括号内」的特殊配对处理（如边缘型的 `100(6)` 与 `101(19)` 两组条目）——**具体规则待原文复核**。

## 5. 计分算法

- 各分量表 = 所属条目答「是」数；各分量表得分范围取决于条目数（如偏执型 0–7、边缘型 0–11）。
- **无总分求和的通行做法**（多数研究只报各分量表分与集群分）；亦有研究报「12 个分量表得分之和」为总分。
- `scoreShift: 0`，无反向、无加权。

### ⚠️ 三条特殊计分规则（必须实现）

1. **第 60 题同时计入分裂样型与分裂型**，但计算**总分时只计一次**。
2. **第 106 题**含 6 个子题：**≥ 2 个**子题答「是」才记 1 分。
3. **第 107 题**含 15 个子题：**≥ 3 个**子题答「是」才记 1 分。

> 这三条都**超出**当前 `likert.js` 的「每题一个级别 → 贡献分求和」模型（`likert.js:44,52,60`）：
> - 规则 1 是**跨分量表共享题目**（与 EDE-Q 第 8 题同类，但那里是同级共享、这里是分量表间共享）；
> - 规则 2、3 是**题内阈值判定**（多子题 → 单分），需要「复合题」类型。

## 6. 分界值与分级（→ `bands`）

### 中文版划界分（杨蕴萍等中文版常模，二级来源）

| 划界分 | 分量表 |
| --- | --- |
| **≥ 3** | 反社会型 |
| **≥ 4** | 偏执型、分裂样型、回避型、强迫型、被动攻击型 |
| **≥ 5** | 分裂型、边缘型、表演型、自恋型、依赖型、抑郁型 |

达到或超过对应划界分即为**筛查阳性**。

### 原版（美国）口径

- 原版各亚型阳性划界分为 **4–5 分**。
- 国内研究者建议：**用于中国大学生时调整为 5–6 分**（二级来源）。

> ⚠️ 中/美两套划界分**不可混用**；且不同研究间存在 4/5/6 的差异，落地时须选定一套并在界面注明。

## 7. 信效度

| 指标 | 数值 | 来源 |
| --- | --- | --- |
| 内部一致性 α（各分量表） | **0.56–0.78** | 杨蕴萍团队全国 13 家单位协作研究（二级） |
| α（总分） | **0.72** | 同上 |
| α（大学生群体） | 0.70–0.83 | 凌辉研究（二级） |
| 重测信度（2–4 周） | **0.50–0.80** | 二级 |
| 分半信度 | 0.50–0.93 | 二级 |
| 灵敏度 | 0.85–0.93 | 二级（不同研究报告 93%–89% 与 0.85–0.89 两组口径） |
| 特异度 | **0.47–0.65** | 二级 |

**⚠️ 关键局限（必须写进 `note`）**：
- **特异度低（0.60–0.65），假阳性率约 35%–40%**——普通人群中筛出的阳性者，**约三到四成实际不符合人格障碍临床诊断标准**。
- **筛查阳性 ≠ 临床诊断**；确诊须由精神科医生通过结构化临床访谈（如 SCID-II / SIDP-IV）综合判断。

## 11. 落地备注（对 PsychoInverse 的建议）——**本量表优先级最低**

1. **⛔ 题项缺失 + 受版权保护 + 题量巨大（107 题）**——三个不利因素叠加，建议**排在最后**（甚至本轮不落地）。
2. **版本必须先定**：99（原版）还是 107（中文版），决定 `nItems` 与全部 `bind`。**推荐中文版 107**（国内数据完整）。
3. **12 个分量表 + 3 个集群，题目完全不重叠**（每个条目只对应一个 DSM-IV 标准条目）→ 若为 107 题 12 组，则结构上是解析解的理想形态；技术上走 `likert.js` 无阻碍。
4. **`bands` 结构特殊**：每个分量表有**各自的划界分**（3 / 4 / 5 三档不同），不是统一区间。当前 `bands` 是 per-scale 的，**可以表达**（每个 scale 用自己的 bands），但需在 `bands` 里体现「≥N 阳性」——建议每个分量表用两段 bands（0–(N-1) 阴性 / N–满分 阳性）。
5. **`note` 必须写明**：特异度低、假阳性 35–40%、筛查阳性 ≠ 诊断。
6. 若未来要支持集群因子（A/B/C 群），需处理「集群分 = 其下各分量表原始分之和」——这是**跨层级聚合**，与 HADS 的 `bind:[0]` 聚合项模式不同（HADS 是题目级聚合），**需要新的聚合表达方式**，属通用能力扩展。
