# SAS · 焦虑自评量表（Zung Self-Rating Anxiety Scale）

> 调研文档，供后续落地为 `sas.data.js` 数据模块使用。字段映射见 `_TEMPLATE.md`。

## 1. 基本信息

| 项 | 值 |
| --- | --- |
| 缩写 / `id` 建议 | `sas` |
| 中文全称 | 焦虑自评量表 |
| 英文全称 | Zung Self-Rating Anxiety Scale (SAS) |
| 编制者 / 年份 | William W. K. Zung，1971 |
| 题数 | 20 |
| 作答格式 | 4 级（症状出现频度） |
| 评定时间范围 | 最近一周 |
| 适用人群 | 具有焦虑症状的成年人 |
| 施测时长 | 5–10 分钟 |
| 维度 | **单维**（总分） |

`blurb` 建议：「选择目标粗分 / 标准分，反推出一份 20 题作答（含 5 道反向题）；或直接导入、编辑并评分。」

---

## 2. 作答格式

```js
const SAS_FMT = makeLikert(4, ['没有或很少时间', '少部分时间', '相当多时间', '绝大部分或全部时间']);
const SAS_FMTS = Array(20).fill('likert');
```

四级说明同 SDS：① 没有或很少时间；② 少部分时间（1–2 天）；③ 相当多时间（3–4 天）；④ 绝大部分或全部时间（5–7 天）。

> 施测注意（资料原文）：SAS 有 **5 项反向项目**，若评定者不理解反向评分会直接影响统计结果。

## 3. 题项原文与计分键

**反向题：`reverse: [5, 9, 13, 17, 19]`**（共 5 题，正向 15 题）。
反向来源：科普中国「焦虑自评量表」词条、光明网、中科院心理所论文、《安宁疗护社会工作服务指南》附录——**多源一致**。

| 2 | 我无缘无故地感到害怕 | I feel afraid for no reason at all. | 正向 |
| 3 | 我容易心里烦乱或觉得惊恐 | I get upset easily or feel panicky. | 正向 |
| 4 | 我觉得我可能将要发疯 | I feel like I'm falling apart and going to pieces. | 正向 |
| 5 | 我觉得一切都很好，也不会发生什么不幸 | I feel that everything is all right and nothing bad will happen. | **反向** |

| 7 | 我因为头痛、颈痛和背痛而苦恼 | I am bothered by headaches, neck, and back pains. | 正向 |
| 8 | 我感觉容易衰弱和疲乏 | I feel weak and get tired easily. | 正向 |
| 9 | 我觉得心平气和，并且容易安静坐着 | I feel calm and can sit still easily. | **反向** |

## 4. 因子 / 维度结构

```js

  name: '总分', fullName: 'SAS 总分', family: 'anx',
  bind: [1..20],
  bandMetric: 'sum',      // 见「落地备注」关于分界值空间的说明
}]
```

SAS 为单维量表，无公认子量表。

---

## 5. 计分算法

1. **正向题**（15 题）：级别 0/1/2/3 → 计 **1 / 2 / 3 / 4** 分。
2. **反向题**（5 题）：级别 0/1/2/3 → 计 **4 / 3 / 2 / 1** 分。
3. **粗分 X** = 20 题之和，范围 **20–80**。
4. **标准分 Y** = `Math.floor(X × 1.25)`，范围 **25–100**。

> 换算示例：粗分 40 → 50；粗分 48 → 60；粗分 56 → 70。

## 6. 分界值与严重程度分级（→ `bands`）

### 6.1 中国常模（标准分空间）

| 标准分 | 分级 | 来源 |
| --- | --- | --- |
| 25–49（< 50） | 无焦虑 | 中国常模（科普中国词条、光明网、中科院心理所论文）——二级 |
| 50–59 | 轻度焦虑 | 同上 |
| 60–69 | 中度焦虑 | 同上 |
| 70–100（≥ 70） | 重度焦虑 | 同上 |

> **口径差异提示**：部分资料写「69 分以上为重度」（科普中国词条），另一些写「70 分以上为重度」（光明网）。二者在整数边界上差 1 分。**建议采用 ≥70**，并在文档中注明存在 69/70 两种写法。

常模参考值（中科院心理所论文引用）：**标准分常模 42.25 ± 7.38**（对应粗分常模 33.8 ± 5.90）。

### 6.2 换算到「粗分空间」的等价区间（**落地建议用这一组**）

引擎在粗分空间求解与枚举目标值，故 `bands` 建议落在粗分上；标准分作展示层换算。

按 `floor(粗分 × 1.25)` 逐点回推：

| 粗分 | 标准分 | 分级（对应 6.1） |
| --- | --- | --- |
| 20–39 | 25–48 | 无/极轻微 |
| 40–47 | 50–58 | 轻度 |
| 48–55 | 60–68 | 中度 |
| 56–80 | 70–100 | 重度 |

（边界校验：粗分 39→48、40→50；47→58、48→60；55→68、56→70。）

```js
bands: [
  { min: 20, max: 39, minInc: true, maxInc: true, severity: '无/极轻微' },
  { min: 40, max: 47, minInc: true, maxInc: true, severity: '轻度' },
  { min: 48, max: 55, minInc: true, maxInc: true, severity: '中度' },
  { min: 56, max: 80, minInc: true, maxInc: true, severity: '重度' },
]
```

## 7. 信效度

- 中科院心理所论文引用：**Cronbach's α = 0.82**（二级来源）。
- 另有研究报告 α 约 0.79–0.85，重测信度因间隔而异——**二级来源，落地前建议复核**。
- **重要局限**（资料原文）：焦虑是神经症的共同症状，故 **SAS 在各类神经症鉴别中作用不大**；焦虑症状的临床分级除参考量表分值外，主要还应依据临床症状（特别是要害症状）的程度来划分。

## 11. 落地备注（对 PsychoInverse 的风险与建议）

1. **可直接套 `likert.js` 解析解**（`binary:false`，李克特 4 级），无需新计分钩子。
2. **反向题写作 `data.reverse: [5, 9, 13, 17, 19]`**——李克特系引擎读 `data.reverse`（`likert.js:44,52,60`），不是 `weights`。
3. **⚠️ 分界值空间（同 SDS）**：通行分级是标准分（粗分×1.25），引擎在粗分空间求解。建议 `bands` 用第 6.2 节粗分区间，界面按 `floor(×1.25)` 展示标准分；或引入换算字段。
4. **分级口径需二选一并注明**（重度 ≥70 还是 >69）。
5. `note` 建议写入资料原文的两条局限：① 焦虑是神经症共同症状，SAS 对神经症鉴别作用不大；② 分级须结合临床症状而非仅看分值。
