## 1. 基本信息

| 项 | 值 |

## 2. 作答格式

```js
const SDS_FMT = makeLikert(4, ['没有或很少时间', '少部分时间', '相当多时间', '绝大部分或全部时间']);
const SDS_FMTS = Array(20).fill('likert');
```

- 四级说明（国内通行）：① 没有或很少时间；② 少部分时间（1–2 天）；③ 相当多时间（3–4 天）；④ 绝大部分或全部时间（5–7 天）。
- **变体**：部分中文资料（如人民网健康版）用「偶尔 / 有时 / 经常 / 持续」，语义等价。建议统一采用上表四档，与 SAS 保持一致。

## 4. 因子 / 维度结构

```js
scales: [{
  name: '总分', fullName: 'SDS 总分', family: 'dep',
  bind: [1..20],          // 1–20 全部
  bandMetric: 'sum',      // 见「落地备注」关于分界值空间的说明
}]
```

SDS 为单维量表，无公认子量表。**不建议**把文献中的探索性因子模型做成 `bind` 分组。

## 5. 计分算法

1. **正向题**：级别 0/1/2/3 → 计 **1 / 2 / 3 / 4** 分。
2. **反向题**：级别 0/1/2/3 → 计 **4 / 3 / 2 / 1** 分。
3. **粗分 X** = 20 题计分之和，范围 **20–80**。
4. **标准分 Y** = `Math.floor(X × 1.25)`（取整数部分），范围 **25–100**。
5. （次要指标）Zung 原版另有「抑郁严重度指数 = 粗分 / 80」，范围 0.25–1.00。国内主要使用标准分，指数仅作参考——**二级来源，落地前建议以原始文献复核**。

> 换算示例：粗分 41 → 51.25 → 51；粗分 43 → 53.75 → 53。

## 6. 分界值与严重程度分级（→ `bands`）

### 6.1 中国常模（标准分空间，资料直接给出的口径）

| 标准分 | 分级 | 来源 |
| --- | --- | --- |
| 25–52（< 53） | 无抑郁 | 中国常模（科普中国词条、人民网健康）——二级 |
| 53–62 | 轻度抑郁 | 同上 |
| 63–72 | 中度抑郁 | 同上 |
| 73–100（> 72） | 重度抑郁 | 同上 |

补充：SDS **总粗分正常上限为 41 分**（中国常模），分值越低状态越好。

### 6.2 换算到「粗分空间」的等价区间（**落地建议用这一组**）

引擎（`likert.js`）在**原始分 / 粗分空间**求解与枚举目标值（`likertTargetScales` 的 `allValues`，`likert.js:270-302`），因此 `bands` 建议直接落在粗分上；标准分仅作展示层换算。

按 `floor(粗分 × 1.25)` 逐点回推：

| 粗分 | 标准分 | 分级（对应 6.1） |
| --- | --- | --- |
| 20–42 | 25–52 | 无/极轻微 |
| 43–50 | 53–62 | 轻度 |
| 51–58 | 63–72 | 中度 |
| 59–80 | 73–100 | 重度 |

（边界校验：粗分 42→52、43→53；50→62、51→63；58→72、59→73。均取整部分。）

```js
bands: [
  { min: 20, max: 42, minInc: true, maxInc: true, severity: '无/极轻微' },
  { min: 43, max: 50, minInc: true, maxInc: true, severity: '轻度' },
  { min: 51, max: 58, minInc: true, maxInc: true, severity: '中度' },
  { min: 59, max: 80, minInc: true, maxInc: true, severity: '重度' },
]
```

### 6.3 原版（Zung，美国）口径——仅作对照，勿混用

Zung 原版常用 **标准分 50** 为分界：50 以下正常、50–59 轻度、60–69 中度、70 以上重度。**与中国常模（53）不同**，落地时须明确采用哪一套并在文档/界面注明。

## 7. 信效度

- 国内外研究报告 Cronbach's α 大致在 **0.78–0.92** 区间，因样本与译本而异（**二级来源**，落地前建议以原始文献复核具体值）。
- 与 Hamilton 抑郁量表（HAMD）等他评工具相关良好，常用于疗效变化的敏感指标。
- SDS 属**筛查 / 严重程度评定**工具，**不能作为诊断依据**。

## 11. 落地备注（对 PsychoInverse 的风险与建议）

1. **可直接套 `likert.js` 解析解**（`binary:false`，李克特 4 级），无需新计分钩子。
2. **反向题写作 `data.reverse: [2,5,6,11,12,14,16,17,18,20]`**——注意：李克特系引擎读的是 `data.reverse`（`likert.js:44,52,60`），**不是** `weights`（那是 MMPI-2 二值引擎的约定）。反向题在「贡献分空间」由 `contribOf` / `levelFromContrib` 处理。
3. **⚠️ 分界值空间是主要风险**：SDS 的通行分级是「标准分 = 粗分×1.25」，而引擎求解与 `likertTargetScales` 的 `allValues` 枚举都在**粗分空间**。当前数据契约**没有**「原分→标准分换算」字段。建议：
   - 方案 A（改动最小）：`bands` 直接用第 6.2 节的粗分区间，界面展示时按 `floor(×1.25)` 显示标准分；
   - 方案 B：新增一个换算字段（如 `scoreScale: { factor: 1.25, floor: true }`），让界面统一处理。
4. **第 19 题（自杀/无价值感）** 需像 PHQ-9 第 9 题那样进 `note` 做风险提示。
5. `severity` 命名建议沿用项目现有风格（PHQ-9 用「无/极轻微 / 轻度 / 中度 / 偏重 / 重度」）。
