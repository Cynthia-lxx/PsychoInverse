## 五、落地时需要新增的「通用能力」（跨量表）

若要把第二、三档全部纳入，以下能力需**在引擎层统一扩展**：

1. **条件判定表达式**（MDQ）：如 `positiveRule: { minScore: 7, requireAll: [{item:14, in:[1]}, {item:15, in:[2,3]}] }`。
2. **原分 → 展示分换算**（SDS / SAS 的 ×1.25）：如 `scoreScale: { factor: 1.25, floor: true }`。
3. **外部变量影响判定**（MMSE 受教育年限、MoCA 教育修正）：「输入变量 + 条件加分 + 上限封顶」。
4. **多维度作答**（LES 的影响程度 × 持续时间 × 次数）：需要 `items.dims` 与自定义聚合公式。
5. **非 Likert 输入类型**：`makeChoice`（MDQ 第 15 题）、开放式数值（EDE-Q 13–18）、**复合题**（PDQ-4+ 106/107）、操作题（MMSE/MoCA）。
6. **跨层级 / 跨分量表聚合**：PDQ-4+ 集群分、EDE-Q Global、EDE-Q 第 8 题与 PDQ-4+ 第 60 题的共享。
7. **前后依赖计分规则**（MMSE 连续减 7 的「错一次只记一次」）。
