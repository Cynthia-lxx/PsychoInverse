# MoCA · 蒙特利尔认知评估（Montreal Cognitive Assessment）

> 调研文档，供后续落地为 `moca.data.js`。字段映射见 `_TEMPLATE.md`。
> **⚠️ 本量表是「检查者施测 + 操作题」量表，且官方有认证/培训要求**——详见第 11 节。

---

## 1. 基本信息

| 项 | 值 |
| --- | --- |
| 缩写 / `id` 建议 | `moca` |
| 中文全称 | 蒙特利尔认知评估（量表） |
| 英文全称 | Montreal Cognitive Assessment (MoCA) |
| 编制者 / 年份 | **Ziad S. Nasreddine 等，2005 年正式发表**（量表版权标注 © Z. Nasreddine MD 2004） |
| 题数 | **30 分**，覆盖 **7 大认知领域**（多个子任务） |
| 作答格式 | 各子任务**答对/完成计分**，非 Likert 等级；含连线、画钟、复述、命名、连续减 7 等操作题 |
| 评定方式 | **检查者施测**（他评） |
| 适用人群 | **轻度认知功能损害（MCI）**的快速筛查；亦用于痴呆筛查 |
| 施测时长 | 约 **10 分钟** |
| 维度 | 视空间与执行功能 / 命名 / 注意 / 语言 / 抽象 / 延迟回忆 / 定向 |

`blurb` 建议：「认知筛查工具，需经培训的施测者操作；不建议作为反算对象，建议以导入评分与展示为主。」

---

## 2. 作答格式

MoCA 各子任务为「完成/未完成」判分，**不是 Likert**：

```js
const MOCA_FMT = makeLikert(2, ['未完成/错误', '完成/正确']);
```

- 各子任务按配分给分（有的子任务 1 分，有的含多个计分点）。
- 总分 **0–30**；**若受教育年限 ≤ 12 年，总分加 1 分**（加完后总分上限仍为 30）。

---

## 3. 题项与配分（7 大领域，合计 30 分）

| # | 领域 | 任务内容 | 配分 |
| --- | --- | --- | --- |
| 1 | **视空间与执行功能** | 数字与字母**交替连线**测验；**复制立方体**；**画钟**（表盘、数字、指针） | **5** |
| 2 | **命名** | 说出图片中动物名称（**狮子 / 犀牛 / 骆驼**） | **3** |
| 3 | **注意** | 数字**顺背**与**倒背**；**警觉性**任务（听到指定字母敲桌）；**从 100 连续减 7** | **6** |
| 4 | **语言** | **复述**复杂句子；**词语流畅性**（限时说词） | **3** |
| 5 | **抽象思维** | 解释两个词语的共同点（如「香蕉—橘子」） | **2** |
| 6 | **延迟回忆** | 先记若干词语，做完全部项目后**回忆**（5 个词） | **5** |
| 7 | **定向力** | 说出**日期、地点**等 | **6** |
| | | **合计** | **30** |

> 记忆的**即刻回忆**环节**不计分**，只有**延迟回忆**计入 5 分。

---

## 5. 计分算法

1. 各子任务按配分累加 → 原始总分 **0–30**。
2. **教育修正**：若**受教育年限 ≤ 12 年，总分 + 1 分**；加完后**总分仍不超过 30**。
3. 无反向题、无加权。
4. ⚠️ 教育修正是**条件性的附加规则**，当前数据契约**无此字段**（对比：CTQ-SF 有 `scoreShift` 但那是常数偏移，不是条件修正）。

## 6. 分界值与分级（→ `bands`）

| 总分 | 判读 |
| --- | --- |
| **≥ 26** | **正常**（Normal ≥ 26/30） |
| **< 26** | 提示认知功能损害，需进一步评估 |

- 官方题本标注：**Normal ≥ 26 / 30；Add 1 point if ≤ 12 yr edu**。
- 亦有资料提到 **25/26 切点在不同人群中的误判问题**（三级来源），但 **26 是官方与主流采用的界值**。
- **无统一的轻/中/重严重程度分级**（MoCA 主要作 MCI 筛查）。

```js
bands: [
  { min: 0,  max: 25, minInc: true, maxInc: true, severity: '低于正常界值（需进一步评估）' },
  { min: 26, max: 30, minInc: true, maxInc: true, severity: '正常范围' },
]
```

## 7. 信效度

- MoCA **在识别轻度认知功能障碍（MCI）方面的敏感性优于 MMSE**、CAMCOG 等常用筛查量表（二级来源，官方与多项研究一致）。
- 已被翻译成 **50 多种语言**；有官方应用（MoCA Duo App）供临床使用。
- **具体 α / 重测信度 / AUC 数值待原文复核**（建议以 Nasreddine 2005 原始文献与官方手册为准）。

### 版本与人群适配

- **MoCA-B（基础版）**：为适应**文盲与低教育程度人群**而开发。
- 另有为不同语言/人群调整的多个版本。

## 8. 中国常模

- MoCA 有中文版本（50 余种语言版本之一）。
- **本次调研未取得可引用的中国常模分界值**；国内多沿用 **≥26** 与**教育年限修正**。
- **落地建议**：首期沿用官方 ≥26 + 教育修正，`note` 注明「暂无本土常模」。

## 11. 落地备注（对 PsychoInverse 的建议）——**与 MMSE 同类，风险最高**

1. **⚠️ 根本性不匹配（同 MMSE）**：MoCA 是**检查者施测的操作性检查**。
   - 任务含**交替连线、复制立方体、画钟、复述句子、限时词语流畅性、抽象概括、连续减 7、延迟回忆**——均非「选一个等级」。
   - 无法映射到 `formats.js` 的「每题一个级别」模型。
2. **⚠️ 教育年限的条件性加分**：`scoreShift` 是常数偏移，而 MoCA 是「**若受教育年限 ≤12 年则 +1**」的**条件修正**，且**上限封顶 30**。当前契约无法表达，需要新的「输入变量 + 条件规则 + 上限封顶」能力。
3. **⚠️ 版权与认证**：MoCA® 是注册商标，官方有**施测者认证要求**。即便技术上能实现，**落地前必须先解决授权问题**——这是本项目清单里**限制最多**的一份。
4. **建议**：
   - **方案 A（推荐）**：**不做反算**，做成**导入评分 + 展示型**工具（录入各领域得分，系统算总分、应用教育修正、给出 ≥26 判定）。
   - **方案 B**：不纳入本轮落地，先解决授权。
5. 若与 MMSE 二选一优先落地：**MMSE 优先**（教育分层界值明确、国内常模完整、无认证要求）；MoCA 因授权问题建议最后或暂缓。
6. **优先级建议：与 MMSE 并列最低，且因授权问题排在 MMSE 之后。**
