# LES · 生活事件量表（Life Event Scale）

> 调研文档，供后续落地为 `les.data.js`。字段映射见 `_TEMPLATE.md`。
> **⚠️ 本量表是「事件 × 多维度打分」结构，不是常规 Likert 求和量表**——详见第 11 节。

---

## 1. 基本信息

| 项 | 值 |
| --- | --- |
| 缩写 / `id` 建议 | `les` |
| 中文全称 | 生活事件量表 |
| 英文全称 | Life Event Scale (LES) |
| 编制者 / 年份 | **杨德森、张亚林，1986 年**编制 |
| 题数 | **48 条**常见生活事件 + **2 条空白项目**（供填写未列出的事件） |
| 作答格式 | **每个事件需打 3 个分**：性质（好/坏）、影响程度（0–4）、影响持续时间（1–4），并记录发生次数 |
| 评定时间范围 | 通常为**过去一年**（亦可按需设定） |
| 适用人群 | 16 岁以上的正常人、神经症、心身疾病、各种躯体疾病患者，以及自知力恢复的重性精神病患者 |
| 施测时长 | 10–20 分钟 |
| 维度 | 三领域（家庭生活 / 工作学习 / 社交及其他）+ 正性 / 负性 / 总刺激量 |

`blurb` 建议：「生活事件为定性 + 定量评估，不适用于常规反算；建议以导入评分与展示为主。」

---

## 2. 作答格式

LES **不是单一 Likert**——每条事件需要三个判断：

| 维度 | 选项 | 计分 |
| --- | --- | --- |
| **事件性质** | 好事 / 坏事 | 决定计入正性还是负性 |
| **影响程度** | 毫无影响 / 轻度 / 中度 / 重度 / 极重 | **0 / 1 / 2 / 3 / 4** 分 |
| **影响持续时间** | 三个月内 / 半年内 / 一年内 / 一年以上 | **1 / 2 / 3 / 4** 分 |
| **发生次数** | — | 一过性事件记实际发生次数；长期性事件不到半年记 1 次，超过半年记 2 次 |

```js
const LES_IMPACT = makeLikert(5, ['毫无影响', '轻度', '中度', '重度', '极重']);
const LES_DUR    = makeLikert(4, ['三个月内', '半年内', '一年内', '一年以上']);
// 另需一个「性质」二值维度（好/坏）与一个次数维度
```

## 4. 因子 / 维度结构（→ `bind`）

LES 的维度不是「题目分组」，而是**三种刺激量**：

| 指标 | 定义 |
| --- | --- |
| **某事件刺激量** | 影响程度分 × 影响持续时间分 × 该事件发生次数 |
| **正性事件刺激量** | 被判为「好事」的各事件刺激量之和 |
| **负性事件刺激量** | 被判为「坏事」的各事件刺激量之和 |
| **生活事件总刺激量** | 正性事件刺激量 + 负性事件刺激量 |

```js
// 若落地，三个「维度」不是 bind 分组，而是三条聚合公式
scales: [
  { name: '正性事件刺激量', fullName: 'LES 正性事件刺激量', family: 'stress_pos' },
  { name: '负性事件刺激量', fullName: 'LES 负性事件刺激量', family: 'stress_neg' },
  { name: '总刺激量',       fullName: 'LES 生活事件总刺激量', family: 'stress' },
]
```

---

## 5. 计分算法

1. 一次性事件（如流产、失窃）记录**发生次数**；长期性事件（如住房拥挤、夫妻分居）不到半年记 1 次，超过半年记 2 次。
2. 由填写者根据自身**实际感受**（而非常理或伦理观念）判断好事/坏事。
3. 影响程度 5 级记 **0–4** 分；影响持续时间 4 级记 **1–4** 分。
4. **某事件刺激量 = 影响程度分 × 持续时间分 × 发生次数**。
5. 分别累加正性、负性；总刺激量 = 正性 + 负性。

> ⚠️ 注意：**影响程度从 0 起，持续时间从 1 起**——乘积为 0 的情况（影响程度=0）意味着该事件刺激量为 0。

## 6. 分界值与分级（→ `bands`）

原量表编制说明给出的参照（**最常用的两个数字**）：

| 总刺激量 | 判读 |
| --- | --- |
| **≤ 20** | 约 **95%** 的正常人一年内的 LES 总分不超过 20 分 |
| **≤ 32** | 约 **99%** 的正常人一年内的 LES 总分不超过 32 分 |
| **> 32** | 高精神负荷，属高危人群，建议加强预防 |

- 这是**百分位参照**而非诊断 cutoff。
- **另有重要结论**（资料原文）：**消极性质的生活事件与疾病最为相关**，中性或积极性质的生活事件致病作用不明显——因此**负性事件刺激量往往比总分更有意义**。
- **落地建议**：`bands` 建议按 0–20 / 21–32 / >32 三档，并**单独呈现负性事件刺激量**。

```js
bands: [
  { min: 0,  max: 20, minInc: true, maxInc: true, severity: '常见范围（约 95% 正常人一年内）' },
  { min: 21, max: 32, minInc: true, maxInc: true, severity: '偏高（约 99% 分位内）' },
  { min: 33, max: 999, minInc: true, maxInc: true, severity: '高精神负荷（高危）' },
]
```

（上限需按实际情况设定；LES 总刺激量无严格理论上限，因含次数与持续时间乘积。）

## 7. 信效度

- LES 在国内应用广泛，用于病因学研究、危机干预指导、高危人群甄别。
- **具体 α / 重测信度数值待原文复核**（建议以《中国心理卫生评定量表手册》为准）。
- **方法论特点**（资料原文）：个体精神刺激评定**不宜使用常模的标准化计分**，而应**分层化或个体化**，并同时包括**定性**（正/负性）与**定量**（刺激量）评估。

## 8. 中国常模

- **本量表即由杨德森、张亚林在中国编制（1986）**，48 条事件为「我国较常见的生活事件」，本身即本土化工具。
- 常模参照：95% 正常人一年内 ≤20 分；99% ≤32 分（见第 6 节）。

## 11. 落地备注（对 PsychoInverse 的建议）——**本量表的关键风险**

1. **⚠️ 结构超出当前数据契约**：LES 每条事件需要**三个输入**（性质、影响程度、持续时间）+ 次数，且分数是**乘积再求和**，不是简单的「级别求和」。
   - 当前 `likert.js` 的模型是「每题一个级别 → `contribOf` 映射为贡献分 → 求和」（`likert.js:44,52,60`）。LES 需要**每题两个级别**（影响 + 时长）并做**乘法**，现有 `items.format` 只允许每题**一个**格式。
   - **可选方案**：
     - **方案 A（推荐）**：不做反算，只做**导入评分 + 展示**（作为纯工具），规避契约扩展。
     - **方案 B**：把 LES 拆成「48×2 = 96 个作答位」（影响 + 时长各一位），但次数仍需额外字段——复杂度高。
     - **方案 C**：为数据契约新增**多维度作答**（`items.dims: ['impact','duration']`）与**自定义聚合公式**——属较大的通用能力扩展。
2. **⛔ 48 条事件文本待补**（第 3 节）。
3. **负性事件刺激量应优先呈现**——资料明确指出负性事件与疾病相关最强。
4. **总刺激量无理论上限**（含次数 × 时长乘积），`bands` 上限需合理设定。
5. **优先级建议**：低于自评类李克特量表；建议作为「导入评分型」工具而非「反算型」工具。
