# SDSS · 社会功能缺陷筛选量表（Social Disability Screening Schedule）

> 调研文档，供后续落地为 `sdss.data.js`。字段映射见 `_TEMPLATE.md`。
> **⚠️ 本量表是「他评/半定式评定」量表，与自评量表性质不同**——详见第 11 节。

---

## 1. 基本信息

| 项 | 值 |
| --- | --- |
| 缩写 / `id` 建议 | `sdss` |
| 中文全称 | 社会功能缺陷筛选量表 |
| 英文全称 | Social Disability Screening Schedule (SDSS) |
| 来源 | 由 WHO 的《社会功能缺陷评定草案》（DAS / Disability Assessment Schedule）改编，国内修订 |
| 题数 | **10** 个项目 |
| 作答格式 | **3 级评定**（0 = 无缺陷 / 1 = 有缺陷 / 2 = 严重缺陷） |
| 评定方式 | **评定者依据知情人（家属/照料者）或会谈资料评定** |
| 评定时间范围 | 通常评**最近一个月**（部分版本为最近 1 年/特定时期） |
| 适用人群 | 精神障碍患者（尤其慢性精神疾病、社区精神病患者） |
| 施测时长 | 10–20 分钟（含会谈） |
| 维度 | 单维（总分）；项目覆盖职业/婚姻/父母职能/社会退缩等 10 个功能领域 |

`blurb` 建议：「选择目标总分，反推 10 个功能领域的评定结果；社会功能缺陷筛查资料参考。」

---

## 2. 作答格式

```js
const SDSS_FMT = makeLikert(3, ['无缺陷', '有缺陷', '严重缺陷']);
const SDSS_FMTS = Array(10).fill('likert');
```

- 3 级计分 **0 / 1 / 2**。
- **无反向题**。
- 总分 **0–20**。

---

## 3. 题项（10 个功能领域）

| 题号 | 领域（中文） | 英文领域 |
| --- | --- | --- |
| 1 | 职业和工作 | Occupation and work |
| 2 | 婚姻职能 | Marital role |
| 3 | 父母职能 | Parental role |
| 4 | 社会性退缩 | Social withdrawal |
| 5 | 家庭外的社会活动 | Social activities outside the family |
| 6 | 家庭内活动过少 | Decreased activities within the family |
| 7 | 家庭职能 | Family role / functioning |
| 8 | 个人生活自理 | Self-care / personal hygiene |
| 9 | 对外界的兴趣和关心 | Interest and concern about the outside world |
| 10 | 责任心和计划性 | Responsibility and planning |

> 每个领域的**具体评定标准**需依据量表手册（各领域有对应的分级描述与提问提纲）。⚠️ **本调研未取得各项目的分级描述原文**，落地前需补。

## 4. 因子 / 维度结构

```js
scales: [{ name: '总分', fullName: 'SDSS 总分', family: 'func',
           bind: [1..10], bandMetric: 'sum' }]
```

单维，10 项求和。

---

## 5. 计分算法

- 每项 0–2 分；总分 **0–20**。
- 判读口径：**总分 ≥ 2 分即为「有社会功能缺陷」**（国内常用标准）。
- `scoreShift: 0`，无反向、无加权。

---

## 6. 分界值与分级（→ `bands`）

| 总分 | 判读 |
| --- | --- |
| 0–1 | 无明显社会功能缺陷 |
| 2–20 | **有社会功能缺陷** |

- 亦有资料按 ≥2 判定后，再按分数粗略区分轻中重，但**未见统一的严重度分级**。
- **落地建议**：`bands` 用二分（0–1 / 2–20），严重程度分级待手册复核。

```js
bands: [
  { min: 0, max: 1,  minInc: true, maxInc: true, severity: '无明显社会功能缺陷' },
  { min: 2, max: 20, minInc: true, maxInc: true, severity: '有社会功能缺陷' },
]
```

## 7. 信效度

- SDSS 在国内精神科广泛应用，信效度有较多研究；评定者间一致性是主要质量指标。
- **具体 α / 评定者间 Kappa 数值待原文复核**（建议以《中国心理卫生评定量表手册》或国内修订文献为准）。

---

## 8. 中国常模

- SDSS 国内应用广泛，**社区正常人群通常总分极低**（多数为 0）。
- **未取得正式中国常模分界值**；临床沿用 **≥2** 判定。

---

## 9. 来源出处

- **一级**：World Health Organization. *Disability Assessment Schedule (DAS / DAS-II)* — SDSS 的原型。（WHO 官方文件）
- **二级**：《中国心理卫生评定量表手册》（中国心理卫生杂志社）——SDSS 中文版、10 项、3 级计分、≥2 判定标准
- **二级**：国内精神科教材与社区精神病学文献（SDSS 应用领域与判读）
- **三级**：网络量表介绍页（结构核对）

## 11. 落地备注（对 PsychoInverse 的建议）——**本量表的关键风险**

1. **⚠️ SDSS 本质是他评/半定式会谈量表，不是自评量表。**
   - 本项目的定位是「给定目标分 → 反求作答」，默认面向**自评**量表。SDSS 需要评定者依据知情人访谈做判断，反算出的「评定结果」在语义上是**评定者的判断序列**，而非受试者的作答。
   - **建议**：要么明确标注 SDSS 为「评定练习/教学演示」用途，要么在落地时把它做成纯展示型（不可求解）。
2. **项目分级描述缺失**：10 个领域各自的 0/1/2 判定标准未取得原文，落地前必须补（否则使用者无法判断该选哪一级）。
3. **无统一严重程度分级**：`bands` 只能用二分（≥2）。
4. 结构上**可直接套 `likert.js` 解析解**（3 级、无反向、纯求和），技术上无障碍——风险在**量表性质**而非技术。
5. 优先级建议：低于自评类量表（SDS / SAS / PCL-5 / CTQ-SF 等）。
