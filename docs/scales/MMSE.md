# MMSE · 简易精神状态检查（Mini-Mental State Examination）

> 调研文档，供后续落地为 `mmse.data.js`。字段映射见 `_TEMPLATE.md`。
> **⚠️ 本量表不是自评量表，是「检查者施测 + 操作题」量表**——详见第 11 节。

---

## 1. 基本信息

| 项 | 值 |
| --- | --- |
| 缩写 / `id` 建议 | `mmse` |
| 中文全称 | 简易精神状态检查（量表） |
| 英文全称 | Mini-Mental State Examination (MMSE) |
| 编制者 / 年份 | **Folstein MF, Folstein SE, McHugh PR，1975** |
| 题数 | **30 项**（资料表述为「12 个问题共 30 项」，亦有称「19 个项目」——口径差异见下） |
| 作答格式 | **答对 1 分 / 答错 0 分**；不适用记 9、拒绝/不理解记 8（累计时 8 与 9 均按 0 计算） |
| 评定方式 | **检查者施测**（他评），含口语作答与操作任务 |
| 适用人群 | 老年人认知功能障碍筛查、痴呆筛查、疗效观察 |
| 施测时长 | 5–10 分钟 |
| 维度 | 定向力（时间 + 地点）/ 即刻记忆 / 注意与计算 / 延迟回忆 / 语言（命名、复述、三步命令、阅读、书写） / 视空间（临摹） |

- **国内版本**：中文版有**两个**译本，分别由**李格**和**张明圆**译制，并各自进行了常模编制（二级来源）。**落地前须确定采用哪一版**。

`blurb` 建议：「认知筛查工具，需检查者施测；不建议作为反算对象，建议以导入评分与展示为主。」

---

## 2. 作答格式

MMSE 的每一项是「**答对 / 答错**」，不是 Likert 等级：

```js
const MMSE_FMT = makeLikert(2, ['错误/不知道', '正确']);   // 级别 0=错, 1=对
```

- 每项正确记 **1** 分，错误或不知道记 **0** 分；**不适合记 9**、**拒绝回答或不理解记 8**，累计总分时 8 与 9 均按 **0** 计算。
- 最高分 **30 分**。

---

## 3. 题项与计分（30 项分解）

| 领域 | 项目内容 | 计分 |
| --- | --- | --- |
| **定向力 · 时间** | 现在是：星期几 / 几号 / 几月 / 什么季节 / 哪一年 | **5** |
| **定向力 · 地点** | 我们在：省市 / 区县 / 街道或乡 / 什么地方 / 第几层楼 | **5** |
| **即刻记忆** | 复述三样东西：**皮球 / 国旗 / 树木**（以第一次答案记分） | **3** |
| **注意力和计算力** | **100 连续减 7**，共 5 次（93 / 86 / 79 / 72 / 65）。若某答案错误但下一答案正确，只记一次错误 | **5** |
| **回忆力** | 回忆刚才的三样东西：皮球 / 国旗 / 树木 | **3** |
| **语言 · 命名** | 命名：手表 / 铅笔 | **2** |
| **语言 · 复述** | 复述「**四十四只石狮子**」（必须完全相同才算正确） | **1** |
| **语言 · 三步命令** | 「用右手拿纸 / 两手对折 / 放在大腿上」三动作 | **3** |
| **语言 · 阅读** | 「请闭上你的眼睛」——**有闭眼动作才给分** | **1** |
| **语言 · 书写** | 写出一句完整的句子 | **1** |
| **视空间 · 结构** | 临摹**两个相交的五边形**（图形须有 10 个角） | **1** |
| | **合计** | **30** |

> 「12 个问题共 30 项」与「19 个项目」两种表述的差异源于**是否把多步任务（如定向力 5 问、三步命令）拆开计数**——30 分的总分与各领域配分是一致的。

## 4. 因子 / 维度结构（→ `bind`）

```js
scales: [
  { name: '定向力',     fullName: 'MMSE 定向力',     bind: [1..10], bandMetric: 'sum' },  // 10 分
  { name: '即刻记忆',   fullName: 'MMSE 即刻记忆',   bind: [11..13], bandMetric: 'sum' }, // 3 分
  { name: '注意与计算', fullName: 'MMSE 注意与计算', bind: [14..18], bandMetric: 'sum' }, // 5 分
  { name: '延迟回忆',   fullName: 'MMSE 延迟回忆',   bind: [19..21], bandMetric: 'sum' }, // 3 分
  { name: '语言',       fullName: 'MMSE 语言',       bind: [22..29], bandMetric: 'sum' }, // 8 分
  { name: '视空间',     fullName: 'MMSE 视空间',     bind: [30],     bandMetric: 'sum' }, // 1 分
  // 总分 30
]
```

（题号为按上表顺序拆成 30 个计分位后的编号，落地时按实际题本编号调整。）

---

## 5. 计分算法

- 各计分项 0 / 1 求和 → **总分 0–30**。
- **无反向题、无加权**。
- ⚠️ 特殊规则：
  - 连续减 7：**若某答案错误但下一答案正确，只记一次错误**（`likert.js` 的逐题独立计分模型**无法表达**这种「前后依赖」规则）。
  - 复述题：必须**完全相同**才算正确。
  - 三步命令、阅读闭眼、临摹图形：均为**操作判分**，不是选择作答。

## 6. 分界值与分级（→ `bands`）

### 6.1 教育分层分界值（**国内最常用，痴呆筛查**）

| 教育程度 | 分界值 | 判读 |
| --- | --- | --- |
| **文盲（未受教育）** | **≤ 17** | 分界值以下为有认知功能缺陷 |
| **小学（受教育年限 ≤ 6 年）** | **≤ 20** | 同上 |
| **中学或以上（受教育年限 > 6 年）** | **≤ 24** | 同上 |

来源：科普中国/百度百科词条、《老年人失能（失智）预防干预服务规范》附录 D（南通市卫健委）等，**多源一致**。

### 6.2 严重程度分级（另一常用口径，不分教育）

| 总分 | 分级 |
| --- | --- |
| 27–30 | 认知功能完整（正常） |
| 21–26 | 轻度认知障碍 |
| 10–20 | 中度认知障碍 |
| 0–9 | 重度认知障碍 |

（另有资料以 **28–30** 为认知功能完整。）

> ⚠️ **两套口径用途不同**：6.1 是**痴呆筛查的教育分层界值**（国内规范采用），6.2 是**严重程度分级**。落地时**不可混用**，建议 `bands` 采用 6.2，把 6.1 放 `note` 并**要求先输入受教育年限**。

## 7. 信效度

- MMSE 具有良好的**重测信度与评分者间信度**。
- 在识别**中重度痴呆**方面表现良好；⚠️ **对轻度认知障碍（MCI）的检测敏感性有限**（资料原文）。
- 与韦氏成人智力测验结果比较一致性较理想（二级来源）。
- **具体 α / 相关系数数值待原文复核**。

## 11. 落地备注（对 PsychoInverse 的建议）——**本量表不适合作为反算对象**

1. **⚠️ 根本性不匹配**：MMSE 是**检查者施测的操作性检查**，不是自评问卷。
   - 项目包含**连续减 7 运算、复述句子、三步动作命令、闭眼动作、书写句子、临摹五边形**——这些**不是「选一个等级」**，而是由检查者判分的操作题。
   - 本项目的核心（给定目标分 → 反求作答）建立在「每题一个级别」的模型上（`formats.js:12-13`）。MMSE 的多项**无法映射为级别选择**。
2. **⚠️ 计分含前后依赖规则**：连续减 7 的「某答案错误但下一答案正确只记一次错误」——`likert.js` 的逐题独立计分**无法表达**（`likert.js:44,52,60` 的 `contribOf` 是逐题独立映射）。
3. **⚠️ 分界值依赖外部变量（受教育年限）**：`bands` 是静态区间，**无法按受教育年限动态切换三套界值**（17 / 20 / 24）。需要新增「输入变量 → 影响判定」的能力。
4. **建议**：
   - **方案 A（推荐）**：**不做反算**，做成**导入评分 + 展示型**工具（用户逐项录入对/错，系统算分并给出教育分层判定）。
   - **方案 B**：仅取其中**可映射为二值作答**的少数项目做简化演示——但会破坏量表的临床完整性，**不推荐**。
5. **若一定要落地**，需要三项新能力：① 操作题/文本题的输入类型；② 跨题依赖的计分规则；③ 受外部变量影响的动态分界值。**这三项都属跨量表通用能力扩展，成本高。**
6. **优先级建议：最低**（与 MoCA 一起排在最后，且优先于 PDQ-4+ 之前考虑其「不可反算」属性）。
