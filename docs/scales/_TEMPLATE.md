# 量表调研文档模板 `_TEMPLATE`

> **用途**：为每个待接入的量表产出一份「可直接落地为 `*.data.js` 数据模块」的离线参考资料。
> **项目**：PsychoInverse（`MMPI-2-Solver`）——纯前端心理学量表反算器。
> **数据契约范式**：`phq9.data.js:8-59`；作答格式工厂 `formats.js:41 makeLikert(n, labels)`、`formats.js:54 makeChoice(labels)`。
> **本阶段只做调研与文档**，不写实现代码；SCL-90 的优化不属于本阶段。

## 二、标准小节（每份文档统一按此顺序）

1. **基本信息**：缩写、中文全称、英文全称、编制者 / 年份、题数、作答格式与级数、适用人群、施测时长。
2. **作答格式**：各等级文本（中），给出 `makeLikert(n, labels)` 或 `makeChoice(labels)` 的建议参数。
3. **题项原文**：表格形式，`题号 | 中文 | 英文 | 计分键（正向/反向）`。题号必须与 `bind` 一致（1 起）。
4. **因子 / 维度结构**：每个因子的名称、包含题号（→ `bind`）、聚合方式（`sum` / `mean`）。
5. **计分算法**：原始分如何计算；反向题如何处理；是否需加权 / 修正项（如 MoCA 教育年限 +1）。
6. **分界值与严重程度分级**（→ `bands`）：区间连续、无空隙与重叠，每条须标注来源。
7. **信效度**：Cronbach's α、重测信度、效度证据（标注来源）。
8. **中国常模**（如有）：常模来源、样本、分界值。
9. **来源出处**：分级列出（见下）。
10. **版权状态与免责声明**：版权方 + 固定声明（见下）。
11. **落地备注**：能否直接套现有引擎（`likert.js` 解析解 / `inverse.js` 退火 / `mbti.js`）；是否需要新计分钩子；风险点。

## 三、来源可信度分级与冲突处理

- **一级**：原始论文 / 官方测验手册（最高优先级；冲突时以其为准，记录 DOI 或出处）。
- **二级**：教科书、权威综述、官方机构网页。
- **三级**：精神科 Wiki、GitHub 仓库、一般网络资源（**仅作补充与线索，不得单独作为分界值依据**）。
- 中英对照：优先采用国内通行译本并注明译者 / 出处；无权威译本时译自英文原文，并标注「**自译待校对**」。
